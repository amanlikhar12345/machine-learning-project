# Machine Learning Projects

A collection of machine learning projects built using Python and Flask. This repository contains multiple real-world prediction, regression, forecasting, and classification applications with web-based interfaces.

## 🚀 Projects

| Project | Description | Model |
|---|---|---|
| Salary Predictor | Predicts salary based on input features | Gradient Boosting |
| Employee Salary Predictor | Predicts employee salary | Polynomial Regression |
| House Price Predictor | Predicts house prices | Lasso Regression |
| Taxi Price Predictor | Predicts taxi fares | Machine Learning |
| Medical Bill Predictor | Predicts medical expenses | Machine Learning |
| Real Price Predictor | Predicts real-estate prices | Gradient Boosting |
| Temperature Predictor | Predicts temperature | Machine Learning |
| Consumption Predictor | Predicts consumption | Linear Regression |
| Vehicle Price Predictor | Predicts vehicle prices | Gradient Boosting |
| Sales Forecasting | Forecasts future sales | Decision Tree |
| Diabetes Prediction App | Predicts diabetes risk | Artificial Neural Network |
